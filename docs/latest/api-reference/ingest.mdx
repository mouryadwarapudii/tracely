---
title: Ingest traces
description: The OTLP/HTTP trace endpoint.
---

```
POST /v1/traces
```

`/api/otlp/v1/traces` is the same endpoint.

## Authentication

```
Authorization: Bearer tr_...
```

or `x-tracely-key: tr_...`.

## Body

An OTLP `ExportTraceServiceRequest`.

| `Content-Type` | Encoding |
|---|---|
| `application/x-protobuf` | Protobuf (default for most SDKs) |
| `application/json` | OTLP JSON: hex trace and span IDs, times as nanosecond strings |

`Content-Encoding: gzip` is accepted. Maximum body size is 16 MB.

## Example

```bash
curl -X POST http://localhost:3000/v1/traces \
  -H "Authorization: Bearer $TRACELY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "resourceSpans": [{
      "resource": {"attributes": [{"key": "service.name", "value": {"stringValue": "curl-demo"}}]},
      "scopeSpans": [{"spans": [{
        "traceId": "5b8efff798038103d269b633813fc60c",
        "spanId": "eee19b7ec3c1b174",
        "name": "chat gpt-4o-mini",
        "kind": 3,
        "startTimeUnixNano": "'$(date +%s)'000000000",
        "endTimeUnixNano": "'$(( $(date +%s) + 1 ))'000000000",
        "attributes": [
          {"key": "gen_ai.operation.name", "value": {"stringValue": "chat"}},
          {"key": "gen_ai.provider.name", "value": {"stringValue": "openai"}},
          {"key": "gen_ai.request.model", "value": {"stringValue": "gpt-4o-mini"}},
          {"key": "gen_ai.usage.input_tokens", "value": {"intValue": "42"}},
          {"key": "gen_ai.usage.output_tokens", "value": {"intValue": "17"}}
        ]
      }]}]
    }]
  }'
```

## Responses

| Status | Meaning |
|---|---|
| `200` | Stored. The body is an empty `ExportTraceServiceResponse` in the request's encoding. |
| `400` | The body is not a valid request |
| `401` | Missing, unknown, or revoked key |
| `413` | Body over 16 MB |
| `503` | ClickHouse is unavailable. Sent with `Retry-After`; OpenTelemetry exporters retry automatically. |

Spans without a trace ID or span ID are dropped silently. See [Concepts](/latest/concepts#attributes-tracely-reads) for the attributes that are read.
