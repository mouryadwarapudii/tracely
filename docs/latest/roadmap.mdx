## In 0.1

- OTLP/HTTP trace ingest (protobuf and JSON) with API keys
- Overview, Traces with span waterfall and search, Sessions with replay
- Costs, Optimizer, Budgets
- Anomaly detection with cause attribution; Slack and webhook alerts
- Prompt hub with versions and a runtime API
- Python SDK: OpenAI and Anthropic, sessions, decorators, prompts
- Docker Compose deployment; light and dark themes

## How Tracely relates to OpenLIT

Tracely was designed after studying [OpenLIT](https://github.com/openlit/openlit), an Apache-2.0 project in the same space, and follows a similar repository layout. Its code is written independently.

**Both have** tracing on OpenTelemetry, cost tracking, and a prompt hub.

**Tracely 0.1 adds** session replay, a cost optimizer, threshold-free anomaly detection with cause attribution, and budgets with Slack and webhook alerts in the base product.

**OpenLIT has, and Tracely does not yet:** evaluations, guardrails, a secrets vault, a model playground, a rule engine, TypeScript and Go SDKs, 70+ integrations, GPU monitoring, and a CLI for coding agents.

This comparison reflects OpenLIT's README as of November 2026.
